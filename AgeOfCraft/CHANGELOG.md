# Changelog

## 0.1.0: Milestone 1, working foundation (unreleased, not yet tested in-game)

- Behavior and resource packs for Bedrock 1.26.50, with stable Script API
  `@minecraft/server` 2.10.0 and `@minecraft/server-ui` 2.2.0.
- Spearman unit with idle (guard) and moving states, in three faction colours.
- Commander Map item: faction picker, recruitment, and the move-to-target,
  rally-to-me and halt orders.
- Two factions with shared treasuries; wood from logs.
- Persistent world save, friendly-fire protection, unit caps, debug commands.
- Build, test, package and validation tooling.
