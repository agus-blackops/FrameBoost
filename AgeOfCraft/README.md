# Age Of Craft

A real-time strategy layer for Minecraft Bedrock Edition, inspired by classic
age-of-empires-style games. You stay a normal Minecraft character while you
explore, gather, build and fight. A **Commander Map** item opens a controller-friendly
strategy menu where you recruit troops and give them orders.

**Status: Milestone 1, a working foundation.** It has one unit (the Spearman), one
gathering mechanic (wood from logs), one command family (move and halt), two factions
and persistent faction treasuries. Nothing has been tested in-game yet; see
[docs/TESTING.md](docs/TESTING.md).

| | |
|---|---|
| Minecraft Bedrock | 1.26.50 or newer (current retail at the time of writing) |
| Script API | `@minecraft/server` 2.10.0, `@minecraft/server-ui` 2.2.0 (both stable, no experiments needed) |
| Build | Node.js ≥ 22.2, TypeScript 5.9, esbuild, vitest |

## Quick start

```sh
cd AgeOfCraft
npm install
npm run check          # typecheck, tests, build, package
# result: dist/AgeOfCraft-0.1.0.mcaddon
npm run mct:validate   # optional: Mojang's Creator Tools validator
```

Open the `.mcaddon` on Windows, Android or iOS to import both packs. Then turn on
both packs for a world. For Xbox and PlayStation players, see
[docs/PLATFORMS.md](docs/PLATFORMS.md). Full steps are in [docs/INSTALL.md](docs/INSTALL.md).

## Playing Milestone 1

1. Join the world. You receive a **Commander Map**; you can also craft one from
   2 paper and 1 stick.
2. Use the map (Xbox: LT, PlayStation: L2, touch: tap and hold or the use button,
   PC: right-click). Pick a faction: **Aster Kingdom** (blue) or **Crimson Dominion** (red).
3. Chop logs. Each log adds 1 wood to your faction's shared treasury.
4. Open the map and choose **Recruit Spearman** (15 wood).
5. Aim at a spot up to 48 blocks away, open the map, and choose **Move to target**.
   Your spearmen march to a rally flag, then return to guard duty.
   **Rally to me** and **Halt** work the same way.

Spearmen attack monsters and the other faction's players and units. They ignore
their own faction, and damage between members of the same faction is cancelled.

`/aoc:status` shows your faction summary. Operators also get `/aoc:debug <on|off|perf|recount|cleanup|givemap|wood|reset>`.

## Layout

```
AgeOfCraft/
  behavior_pack/      manifest, entities, items, recipes, scripts/main.js (built)
  resource_pack/      manifest, client entities, models, animations, render controllers, textures, texts
  src/
    config/           tunables (caps, distances, intervals)
    data/             gameplay data: factions, units, resources, shared identifiers
    core/             pure logic with no game API: treasury, order book, scheduler, save schema
    managers/         game-facing modules (Civilization, Economy, Unit, Squad, Command, UI, Save, Performance)
    main.ts           wiring and startup
  tests/              core logic tests and pack-consistency tests
  tools/              build, texture generator, packager, validator wrapper
  docs/               install, platforms, testing, architecture, milestone reports
```

All textures are generated by `tools/generate-textures.mjs`, so the art is original.
No Mojang or Age of Empires assets are copied. The spearman model, animations and
render controllers are original files too; the only vanilla thing they reference
is the `entity_alphatest` material.
